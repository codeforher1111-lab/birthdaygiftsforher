A LITTLE BIRTHDAY WORLD — FULLY SEPARATED

Every page has its own HTML, CSS and JavaScript file:
- index.html / index.css / index.js
- pages/surprise.html / surprise.css / surprise.js
- pages/birthday-check.html / birthday-check.css / birthday-check.js
- pages/wish.html / wish.css / wish.js
- pages/letter.html / letter.css / letter.js
- pages/gifts.html / gifts.css / gifts.js
- pages/finale.html / finale.css / finale.js

config.js stores the birthday name, birthday date, signature, letter text, gifts, and song filenames.
You can still edit each page's own CSS and JS separately. The shared config only stores content values.

Run:
1. Extract the ZIP.
2. Open this folder in VS Code.
3. Open index.html in a browser or run it with VS Code Live Server.
4. No Node.js is required.

Songs:
Add MP3 files under assets/audio named song-1.mp3 through song-7.mp3.
The music button uses one song index per page.
